## Project Overview
A food delivery application for Addis Ababa. Built with Next.js App Router, featuring server components, ISR, authentication, and a live tracking dashboard.

## Setup (From a Fresh Clone)
1. `git clone <your-repo-url>`
2. `cd Module_03/addis-eat`
3. `npm install`
4. Copy `.env.example` to `.env.local` and fill in the values.
5. `npm run dev`
